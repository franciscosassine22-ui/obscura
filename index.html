Detection uses a COCO-SSD single-shot detector via TensorFlow.js, executed locally through WebGL. Redaction is applied on a canvas and re-encoded on export, so the saved file carries no original pixel data in the redacted regions and no EXIF metadata. Typical uses: publishing street-level or site-survey imagery under GDPR, sharing incident photos, or removing bystanders and screens before a document leaves an organisation.
